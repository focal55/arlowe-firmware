<execution_notes>
- Use `execFile('systemctl', ['start', '--no-block', 'arlowe-factory-reset@dashboard.service'])`, the same argv pattern as the connectivity routes; never a shell string. `ARLOWE_SYSTEMCTL_MODE=system` is already set in the unit.
- The dashboard itself is stopped by the reset; the 202 must be sent before that matters, which `--no-block` guarantees.
- Wrong-password attempts count toward the login throttle (08-09's `Throttle`), so the reset form cannot be used to brute-force the password.
- The settings page is minimal by scope: Phase 11 owns the full settings view.
</execution_notes>
