<execution_notes>
- Driver callbacks (research Pattern 9): `on_button_press(cb)`, `on_button_release(cb)`; `button_pressed()` is HIGH when pressed. The callbacks run on the GPIO thread: have them only enqueue events; the render loop drains and ticks the gesture, so drawing stays on one thread.
- Timings from ADR-0013: countdown visible from 3.0 s held, value `ceil(10 - held)`; ARMED at 10.0 s with the LED red and "Release, then press to confirm"; confirm window 5.0 s after release.
- On TRIGGERED: `subprocess.run(["systemctl", "start", "--no-block", "arlowe-factory-reset@button.service"])`. The face runs as `arlowe`; the existing polkit prefix rule allows it. Log "factory reset requested (button)".
- The face runs under the voice venv's python. `reset_gesture.py` is stdlib only.
</execution_notes>
