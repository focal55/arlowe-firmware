<feature>
  <name>NetworkManager wrapper</name>
  <files>runtime/pair/netman.py, runtime/pair/tests/test_netman.py</files>
  <behavior>
    - `session_credentials(device_id)` → `(ssid, psk)`; ssid is `Arlowe-Setup-` + first 4 chars; psk is 12 chars from the alphabet; two calls give different psks.
    - `radio_on()` runs `nmcli radio wifi on`.
    - `scan()` runs `nmcli -t -f SSID,SIGNAL,SECURITY device wifi list --rescan yes`, parses escaped colons, drops empty SSIDs, dedupes by strongest signal, returns `[{"ssid", "signal", "secure"}]` sorted by signal.
    - `ap_up(ssid, psk)` runs `nmcli connection add save no type wifi ifname wlan0 con-name arlowe-setup autoconnect no ssid <ssid> …` with the WPA2 settings, then `nmcli connection up arlowe-setup`. `ap_down()` runs `nmcli connection down arlowe-setup` then `delete`, tolerating "not found".
    - `join(ssid, psk)` runs `nmcli --wait 45 device wifi connect <ssid> password <psk> ifname wlan0` (no `password` pair for an empty psk). On failure it deletes the connection named `<ssid>` and raises `JoinError(kind)`.
    - `wifi_profiles()` → UUIDs of every `802-11-wireless` connection from `nmcli -t -f UUID,TYPE connection show`. `delete_profile(uuid)`.
    - `saved_ssid_profile(ssid)` deletes a saved profile after a later failure (the invariant: an unpaired unit has no saved networks).
    - Logging records the action and outcome only.
  </behavior>
  <implementation>`NetMan(runner=subprocess.run, nmcli="nmcli")`. The runner receives argv lists; tests point `nmcli` at the fake.</implementation>
</feature>
