<execution_notes>
- Request file contract (08-20 writes it): `/run/arlowe-pair/commit-request.json` = `{"display_name": "<as typed>"}`. The helper derives the slug itself; it does not accept a slug from the daemon.
- `#!/usr/bin/python3`; the unit runs `ExecStart=/usr/bin/python3 /opt/arlowe/runtime/cli/pair-commit` so the declared python3 floor covers it and no allowlist entry is needed. It inserts `/opt/arlowe/runtime/lib` (or `ARLOWE_LIB`) on `sys.path`, as `runtime/cli/identity` does.
- Exit codes: 0 applied; 2 bad request (missing, symlink, too big, not JSON); 3 name rejected; 4 a system command failed. The daemon treats any non-zero as `setup_failed`.
- `/etc/hosts`: replace the `127.0.1.1` line, or append one if absent; keep every other line byte-for-byte. Rewrite in place (the unit can write the file, not `/etc`).
- `hostnamectl set-hostname <slug>` then `hostnamectl set-hostname --pretty "<display_name>"`. Then `systemctl restart avahi-daemon` (avahi 0.8 does not follow hostname changes by itself; LOW confidence, and the restart is harmless either way).
- Unit: `Type=oneshot`, no `User=`, no `[Install]`, `RestrictAddressFamilies=AF_UNIX`, `ReadWritePaths=/etc/hosts`, `ProtectHostname=no`, the rest of the hardening block as `arlowe-identity-init.service`.
</execution_notes>

<feature>
  <name>Hostname commit helper</name>
  <files>runtime/cli/pair-commit, tests/phase-8/test_pair_commit.py</files>
  <behavior>
    - Valid request "Kitchen Test" → hostnamectl shim called `set-hostname kitchen-test` then `set-hostname --pretty Kitchen Test`; `/etc/hosts` 127.0.1.1 line becomes `127.0.1.1\tkitchen-test`; other lines unchanged; systemctl shim called `restart avahi-daemon`; exit 0.
    - `/etc/hosts` without a 127.0.1.1 line → appended.
    - Request file is a symlink → exit 2, nothing changed.
    - Request larger than 4 KB → exit 2.
    - Not JSON / missing key → exit 2.
    - A name built from a banlist entry (read at test time) → exit 3, nothing changed.
    - hostnamectl shim fails → exit 4, `/etc/hosts` unchanged.
    - The unit file: `Type=oneshot`, no `[Install]`, `ExecStart=/usr/bin/python3 /opt/arlowe/runtime/cli/pair-commit`, name starts with `arlowe-`.
  </behavior>
  <implementation>Order: validate everything, run hostnamectl, then hosts, then avahi, so a rejected or failed request changes nothing on disk.</implementation>
</feature>
