<feature>
  <name>Display name to hostname</name>
  <files>runtime/lib/arlowe_hostname.py, runtime/lib/tests/test_arlowe_hostname.py</files>
  <behavior>
    - `slugify("Kitchen Test")` → `"kitchen-test"`; `slugify("Café  Nº5!")` → `"cafe-no5"`; `slugify("--a--b--")` → `"a-b"`; a 100-character name is cut to 63 with no trailing hyphen.
    - `validate_display_name(name)` returns `(display_name, slug)` or raises `HostnameRejected(reason)` with reason in {`empty`, `too_long` (display name > 32), `no_usable_characters`, `reserved`, `not_allowed`}.
    - `reserved`: `localhost` and slugs that are all digits.
    - `not_allowed`: the slug contains any hashed banlist entry as a substring. The error text never names the entry.
    - Every output slug matches `^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$`.
    - The banlist file path defaults beside the module and can be overridden with `ARLOWE_HOSTNAME_BANLIST` for tests.
  </behavior>
  <implementation>
    Slug: NFKD, drop combining marks, lowercase, map every char outside `[a-z0-9]` to `-`, collapse runs, strip hyphens, trim to 63, strip again. Banlist check: for each `(length, digest)`, hash every substring of that length and compare. `gen-hostname-banlist.py [--check]` reads `scripts/sanitize/banlist.txt`, keeps hostname-shaped entries, writes sorted `[{"length": n, "sha256": h}]`; `--check` exits 1 when the committed file differs.
  </implementation>
</feature>
