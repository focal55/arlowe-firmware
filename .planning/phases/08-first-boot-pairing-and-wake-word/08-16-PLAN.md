<feature>
  <name>Login and logout</name>
  <files>runtime/dashboard/app/api/auth/*, runtime/dashboard/app/login/page.tsx, runtime/dashboard/lib/auth/credential.ts</files>
  <behavior>
    - Right password (the 08-09 vector's) with a credential file and session key present → 200, `Set-Cookie: arlowe_session=…; HttpOnly; SameSite=Strict; Path=/; Max-Age=2592000`, no `Secure`.
    - Wrong password → 401 `{"error":"invalid_credentials"}`, no cookie.
    - Six wrong in a row → the sixth is 429 `{"error":"too_many_attempts"}` even with the right password, until 30 s pass.
    - No credential file → 401 for any password.
    - `Origin` present and not matching `Host` → 403.
    - Logout → 200 with an expired `arlowe_session` cookie.
    - A malformed JSON body → 400.
  </behavior>
  <implementation>Route handlers read the state dir per request (the files change at pairing and reset).</implementation>
</feature>
