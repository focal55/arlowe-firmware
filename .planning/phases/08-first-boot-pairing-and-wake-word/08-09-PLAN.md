<execution_notes>
- Paths come from `ARLOWE_DASHBOARD_STATE_DIR` (default `/var/lib/arlowe/dashboard`): `owner-credential.json` (`{"hash", "created_at"}`) and `session.key` (32 raw bytes). The pairing daemon (08-20) writes both.
- Accept only `$argon2id$v=19$m=…,t=…,p=…$<salt>$<hash>` (unpadded standard base64, as argon2-cffi emits). Reject anything else as false, never throw on malformed input.
- Generate the vector once with `python3 -c "from argon2 import PasswordHasher; print(PasswordHasher(time_cost=3, memory_cost=65536, parallelism=4, hash_len=32, salt_len=16).hash('correct horse battery'))"` (pip `argon2-cffi` locally is fine for generating it) and commit `{password, phc}`. It is a test vector, not a secret.
- Local Node must be ≥ 24.7.0 (`node --version`) or the argon2 cases will fail for the wrong reason.
- Do not touch `app/api/middleware/auth.ts` here; 08-21 deletes it.

<feature>
  <name>Dashboard auth primitives</name>
  <files>runtime/dashboard/lib/auth/*.ts, runtime/dashboard/tests/unit/auth-*.test.ts</files>
  <behavior>
    - `verifyPassword(vector.phc, vector.password)` → true; wrong password → false; `$argon2i$…` → false; `$argon2id$v=16$…` → false; garbage → false.
    - `issueSession(key, now)` → cookie value `<b64url(payload)>.<b64url(hmac)>` with `exp = now + 30 days`.
    - `readSession(value, key, now)` → payload when valid; null when expired, when a payload byte or signature byte changes, when the key differs, when the value has no dot, or when it is empty.
    - `loadSessionKey(dir)` → null when the file is absent or not 32 bytes.
    - `SESSION_COOKIE = "arlowe_session"`; cookie attributes helper returns `HttpOnly; SameSite=Strict; Path=/; Max-Age=2592000` and never `Secure`.
    - `Throttle`: after 5 failures `blocked(now)` is true for 30 s, then false; a success resets it.
  </behavior>
  <implementation>Research's PHC verify example is the base. `createHmac('sha256', key)`; compare digests with `timingSafeEqual` after a length check.</implementation>
</feature>
