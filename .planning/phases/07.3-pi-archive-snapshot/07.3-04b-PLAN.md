<objective>
Switch pi-gen's Pi-side source to the flat repo, and wire the build to create the repo beforehand and swap it back out afterwards. All three land in one PR.

Purpose: SC2. The flat repo replaces `raspi.list` in stage0, `copy_previous` carries it through stage1, stage2 and stage-arlowe with no upstream edits, and plan 04a's `pi_archive_swap_back` removes it before the rootfs is measured (research Patterns 2 and 4). The overlay introduces a `file:` source into the image and the swap-back removes it, so they must merge together.

The overlay implements both modes: an overlay edit needs a hand re-recorded digest and should happen once. `build-image.sh` accepts only `pinned` until plan 07a adds record mode with its stop-before-partitioning, so no commit on main can build an image from the live archive.
