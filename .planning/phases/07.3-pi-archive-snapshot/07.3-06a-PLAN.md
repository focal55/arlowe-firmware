**`tests/phase-07.3/probe-pi-archive.sh`** (host tools: curl, python3, PyYAML; `set -uo pipefail`).

`--retention`:
- For every `packages` and `resolve_only` entry, run `curl -sfI --retry 2 <url>`.
- Fail on a status other than 200, or on a `Content-Length` other than `size`.
- Report every failure, then end with: "the Raspberry Pi pool no longer serves <file>; the build host cache and the CI cache are now the only copies; see third_party/pi-archive/INSTALL.md."
- Floor: fewer than 50 URLs is a failure.
- On success, print `N/N pinned debs still served at their pinned size`.

`--state`:
- Print three `key<TAB>value` lines:
  - `inrelease_date`: the `Date:` from `http://archive.raspberrypi.com/debian/dists/bookworm/InRelease`
  - `packages_gz_sha256`: the sha256 of `…/main/binary-arm64/Packages.gz`
  - `pinned_moved`: the count of manifest `packages` whose live-index version differs from the pin
- Then print one `moved<TAB>name<TAB>pinned<TAB>live` line per moved package.
- Exit 0 unless a fetch fails.
- Comment that this fetch is unsigned and trusted for nothing: it only fingerprints publishes.
