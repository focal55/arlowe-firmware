Add a `check` subparser that follows research Pattern 6:
1. Parse the installed set, the manifest, the kernel names and version, the flat index and the Debian lists. An empty installed set exits 2.
2. **Index equality.** The `(name, version, arch, filename, sha256)` set from the flat index must equal the one from `packages + resolve_only`.
3. **Forward.** Every `packages` entry must be installed at exactly its version and arch. Report the actual version, or "not installed".
4. **resolve_only.** None of these may be installed.
5. **Reverse.** Every installed `(name, version, arch)` must be attributable to (a) a `packages` entry, (b) a Debian stanza at that name and version whose arch matches or is `all`, (c) the kernel pin, or (d) `--allow-local`.
6. Report every failure, then exit 1. On success, print the summary line and exit 0.

Update the docstring to cover both subcommands.
