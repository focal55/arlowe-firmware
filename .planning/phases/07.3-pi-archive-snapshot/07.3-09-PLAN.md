<task type="auto">
  <name>Task 1: Prove the archive moved a pinned package (gate; may end WAITING)</name>
  <files>(none; evidence only)</files>
  <action>
Preconditions:
- 08's reference PR is merged.
- At least 24 h have passed since the build-A time recorded in 08's SUMMARY.

Run `bash tests/phase-07.3/probe-pi-archive.sh --state | tee build/pi-archive-state-B.txt` on the development machine or the build host.

REQUIRED, all three:
1. `inrelease_date` differs from state A.
2. `packages_gz_sha256` differs from state A.
3. `pinned_moved` ≥ 1. At this moment the live index serves a different version of at least one package the image pins.

If any fails, record the output and the time, report WAITING, and stop. Record both state files verbatim in the SUMMARY.
  </action>
  <verify>
    diff build/pi-archive-state-A.txt build/pi-archive-state-B.txt | grep -cE '^[<>] (inrelease_date|packages_gz_sha256)'   # expect: 4
    awk -F'\t' '$1=="pinned_moved"{exit !($2>=1)}' build/pi-archive-state-B.txt && echo "pinned package moved"                # REQUIRED
  </verify>
  <done>Proven: the archive published, and it now serves a different version of at least one pinned package. Or the plan stopped in the WAITING state with timestamped evidence.</done>
</task>

<task type="auto">
  <name>Task 2: Build B without accept or fetch, and the SC4 evidence</name>
  <files>(none; evidence only)</files>
  <action>
Sync main, including 08's reference, to the build host. The worktree must be clean. Assert `env | grep -cE '^ARLOWE_(INPUTS_ACCEPT|PI_ARCHIVE_FETCH)='` is 0: build B relies on the local cache alone. Evidence, verbatim in the SUMMARY:
- **Positive control:** the count of flat-repo apt lines is > 0. If it is 0, STOP, exactly as in 08.
- The count of Pi-archive fetches is 0.
- `Build inputs identical to …`. **This line is SC4:** the diff gate exited 0 without an accept.
- The 0-off-pin line, the check-pass line, and `Build complete`.
- For every `moved` line in state B, read the package's installed version from the rootfs's `var/lib/dpkg/status` (via sudo). It must equal the PINNED version, not the live one.
  </action>
  <verify>
    LOG_B="${LOG_B:-build/logs/phase-07.3-build-B.log}"   # set to pi-gen's build.log if 08 found apt output there
    test "$(grep -cE '(Get|Hit|Ign|Err):[0-9]+ file:/var/local/arlowe-pi-archive' "$LOG_B")" -gt 0 || { echo "POSITIVE CONTROL FAILED"; exit 1; }
    test "$(grep -cE '(Get|Hit|Ign|Err):[0-9]+ https?://archive\.raspberrypi\.com' "$LOG_B")" -eq 0 || { echo "Pi-archive fetch"; exit 1; }
    grep -c 'Build inputs identical to' "$LOG_B"                                            # expect: 1
    grep -c 'reference re-recorded' "$LOG_B"                                                # expect: 0
    grep -c 'Pi archive resolution pinned: [0-9]* flat-repo list files, 0 off-pin' "$LOG_B"  # expect: 1
    grep -c 'Build complete' "$LOG_B"                                                       # expect: 1
  </verify>
  <done>Build B matched build A's inputs with no accept and no fetch, installed the pinned versions of packages the live archive has since moved, and emitted an image.</done>
