<task type="auto">
  <name>Task 2: Implement the variants (GREEN)</name>
  <files>scripts/lib/pi-archive-manifest.py</files>
  <action>
- `open_index`: dispatch on suffix. Plain, `.gz` (gzip) and `.xz` (lzma) are supported. Any other compression suffix exits 2 with this explanation: apt in a docker image stores `.lz4` because of `/etc/apt/apt.conf.d/docker-gzip-indexes`, so delete that file before `apt-get update`.
- `--installed-status FILE`, mutually exclusive with `--installed-reference` (exactly one is required). Read only stanzas whose `Status:` is `install ok installed`, taking Package, Version and Architecture.
- `--resolve-only NAME[=VERSION]` (repeatable):
  - If the package is installed, fail.
  - Otherwise collect the Pi stanzas for NAME, filtered by VERSION when one is given. Exactly one distinct version must remain; if not, fail and list them.
  - Emit it under `resolve_only:` with `why: "named by an upstream pi-gen package list as a removal marker; apt must be able to locate it, it is never installed"`.
  - A duplicate filename across `packages` and `resolve_only` is a failure.
- Update the docstring.
  </action>
