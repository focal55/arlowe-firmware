  <name>Task 1: record + stt — resolve capture device via arlowe_audio CLI</name>
  <files>runtime/cli/record, runtime/cli/stt</files>
  <action>
Both scripts currently invoke `arecord -D plughw:2,0 ...`. Replace the literal with a resolved capture device.

Add near the top of each script (after the shebang/set-flags), a resolution line that prefers an explicit env override, then the resolver, then a literal fallback:

```bash
ARLOWE_LIB="${ARLOWE_LIB:-/opt/arlowe/runtime/lib}"
CAPTURE_DEV="${ARLOWE_ALSA_DEVICE:-$(PYTHONPATH="$ARLOWE_LIB" python3 -m arlowe_audio --resolve-capture 2>/dev/null)}"
CAPTURE_DEV="${CAPTURE_DEV:-plughw:2,0}"
```

Then change `arecord -D plughw:2,0` to `arecord -D "$CAPTURE_DEV"`.

Preserve each script's existing format flags exactly — note `record` uses `-c 2` (stereo) and `stt` uses `-c 1` (mono); do NOT normalize them, that channel difference is pre-existing and out of scope. Keep the change to the device argument only.
